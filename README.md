# Cake Shop — Cruffins Landing Page

A static bakery landing-page project built with HTML and CSS. It presents product images, promotional sections, and a tea-time feature with a local video asset.

## Preview locally

Clone the repository, then open `index.html` in a web browser. There is no build step or package installation.

For a local web server, run this from the repository folder if Python 3 is installed:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Open http://localhost:8000.

## Repository guide

| Path | Purpose |
| --- | --- |
| [index.html](index.html) | Page structure and content |
| [style/style.css](style/style.css) | Page styling |
| `style/` | Images, font, and video assets |

## Project scope

This is a front-end presentation project. Navigation links use placeholder targets, and the page does not implement ordering, payments, or a backend. Promotional text is sample page content.

The page references an external Swiper stylesheet, so loading that stylesheet requires an internet connection. Existing asset and footer credits are preserved in the source.
